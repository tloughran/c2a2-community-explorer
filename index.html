Data notes and caveats

This interface is built from the rebuilt workbook rather than directly re-crawling the web. It inherits the dataset’s main caveat: many narrative summaries are subtype-grounded working descriptions anchored to official site identity or structured source metadata, and most email fields still read none located.

The point of this first-pass web layer is to make the directory inspectable, filterable, and ready for the next step: an enrichment agent that can verify, expand, and normalize records.
